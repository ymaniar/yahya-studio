# Caramelio approved media package

This package contains renamed, descriptive filenames for the approved Caramelio media.

## Folders

- `images/` — approved Caramelio photos with clean names
- `videos/` — approved Caramelio ambience video
- `docs/media-mapping.txt` — mapping from original raw filenames to clean names
- `docs/contact-sheet.jpg` — visual reference sheet for choosing images

## Usage

Copy this entire `assets/` folder into:

`clients/caramelio/assets/`

Then reference media like:

- `assets/images/facade-entrance-01.jpg`
- `assets/images/terrace-01.jpg`
- `assets/images/interior-dining-01.jpg`
- `assets/images/pastry-box-01.jpg`
- `assets/videos/villa-ambience-01.mp4`

Do not use the original raw filenames in website code.

## Important note

`staff-service-01.jpg` includes a visible person. Use it only if Caramelio explicitly approves public website use of that image.
